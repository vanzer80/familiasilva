## Uso correto

- Usar o mesmo arquivo nos perfis oficiais de Instagram, Facebook, TikTok, YouTube e X.
- Enviar o PNG quadrado original, sem criar previamente uma máscara circular; cada plataforma deve aplicar seu próprio recorte.
- Em ajuste manual, manter o enquadramento central e o menor zoom possível, preservando os sete rostos.
- Não aplicar filtros, retoque automático, remoção de fundo, texto, logo, borda, vinheta ou recomposição dos personagens.
- Novas versões devem receber numeração própria (`V02`, `V03` etc.) e nova validação explícita.

## Limite de cânone

Esta é uma imagem institucional aprovada para identificação dos perfis da série. Ela não substitui nem altera as MASTERs individuais dos personagens, que permanecem como referências faciais primárias para novas gerações.
