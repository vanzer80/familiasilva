# Família Silva

**Status:** FASE DE DESENVOLVIMENTO / PRÉ-PRODUÇÃO

Família Silva é uma sitcom familiar brasileira original, produzida com apoio de Inteligência Artificial, criada para funcionar como uma produção audiovisual escalável a muitas temporadas e centenas de episódios.

Este repositório é a fonte oficial de verdade do projeto. Ele organiza cânone, continuidade, personagens, cenários, episódios, prompts, assets e processos de produção.

## Objetivo

Manter uma base simples, objetiva e confiável para que a série possa crescer sem perder consistência narrativa, visual e sonora.

## Filosofia

- Consistência visual e narrativa em todos os materiais.
- Continuidade clara entre episódios, temporadas, personagens e cenários.
- Personagens recorrentes documentados antes de virarem cânone.
- Produção assistida por IA com revisão humana e registro de decisões.
- Proteção de propriedade intelectual própria: o projeto pode se inspirar em dinâmicas de sitcom familiar brasileira, mas não copia personagens, histórias, nomes, cenários ou elementos protegidos de outras obras.

## Regra de cânone

Somente informações aprovadas e registradas nos documentos oficiais deste repositório são cânone.

Informações marcadas como `TODO`, `A DEFINIR`, conceito, rascunho ou em desenvolvimento não são cânone até aprovação explícita.
