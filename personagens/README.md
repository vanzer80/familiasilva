# Personagens

Este diretorio registra personagens da serie Família Silva.

Somente personagens aprovados e documentados como canon fazem parte oficialmente da serie.

## Convencao de IDs

Use `CHAR-001`, `CHAR-002`, `CHAR-003` e assim por diante.

## Como criar um personagem

1. Copie [templates/TEMPLATE-PERSONAGEM.md](templates/TEMPLATE-PERSONAGEM.md).
2. Preencha apenas informacoes aprovadas.
3. Use `TODO` ou `A DEFINIR` para campos indefinidos.
4. Vincule a **IMAGEM MESTRE OFICIAL** quando houver asset aprovado em [../assets/personagens/](../assets/personagens/).
5. Atualize [../docs/CONTINUIDADE.md](../docs/CONTINUIDADE.md) se o personagem virar canon.

## Status possiveis

- Conceito.
- Em desenvolvimento.
- Visual em desenvolvimento.
- Aprovado.
- Canon.
