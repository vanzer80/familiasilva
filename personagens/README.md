## Regra de permanência

- Nunca reutilizar ou renumerar um Character ID aprovado.
- A ficha-base é a fonte de verdade do ID e do nome oficial.
- Documentos de personalidade apenas referenciam a ficha-base; não criam nem alteram IDs.
- Aparência, figurino, voz, imagem MASTER e demais campos visuais continuam `A DEFINIR` quando assim marcados nas fichas.

## Como criar um personagem

1. Consulte este cadastro para reservar o próximo ID sem reutilizar números.
2. Copie [templates/TEMPLATE-PERSONAGEM.md](templates/TEMPLATE-PERSONAGEM.md).
3. Preencha apenas informações aprovadas.
4. Use `TODO` ou `A DEFINIR` para campos indefinidos.
5. Vincule a **IMAGEM MESTRE OFICIAL** somente quando houver asset aprovado em [../assets/personagens/](../assets/personagens/).
6. Atualize [../docs/CONTINUIDADE.md](../docs/CONTINUIDADE.md) se o personagem virar cânone.

## Status possíveis

- Conceito.
- Em desenvolvimento.
- Visual em desenvolvimento.
- Aprovado.
- Cânone.
