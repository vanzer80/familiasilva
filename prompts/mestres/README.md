# Prompts Mestres Aprovados

Este diretório recebe apenas instâncias completas de prompts promovidas explicitamente a mestre.

A arquitetura oficial não fica duplicada aqui: ela permanece em [../templates/TEMPLATE-MESTRE-VIDEO.md](../templates/TEMPLATE-MESTRE-VIDEO.md).

## Regra de promoção

Um prompt só entra neste diretório quando:

1. o texto exato usado na geração foi recuperado;
2. referências, ferramenta e configuração foram registradas;
3. o resultado foi avaliado;
4. a dimensão aprovada foi declarada;
5. houve aprovação explícita para torná-lo mestre.

Os prompts exatos dos testes históricos ainda não recuperados não devem ser reconstruídos por suposição. Seus aprendizados estão preservados em [../../docs/APRENDIZADOS-DE-VIDEO.md](../../docs/APRENDIZADOS-DE-VIDEO.md) e [../../producao/](../../producao/).
