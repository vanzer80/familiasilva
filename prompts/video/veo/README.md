# Veo

Todo prompt para Veo deve partir de [../../templates/TEMPLATE-MESTRE-VIDEO.md](../../templates/TEMPLATE-MESTRE-VIDEO.md).

## Regras obrigatórias

- Fornecer todo o contexto necessário na execução atual.
- Usar somente a referência aprovada própria de cada personagem.
- Preservar `Character Visual Continuity`, `Series Rendering Style Continuity`, `Costume Continuity` e `Environment Continuity`.
- Preservar a relação canônica quando houver mais de um personagem.
- Atribuir literalmente fala, voz e lip sync ao personagem correto.
- Declarar personagens silenciosos para impedir fala ou movimento labial indevido.
- Aplicar `Photorealistic / Warm Cinematic Realism` sem nomes de estúdios, franquias, obras ou artistas.
- Registrar a geração em [../../../producao/testes/](../../../producao/testes/) antes de promover qualquer resultado.
