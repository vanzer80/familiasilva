# VEO

Prompts para Veo devem preservar obrigatoriamente a identidade do personagem, rosto, corpo, idade aparente aprovada, cabelo, figurino, proporcoes, relacao entre personagens, identidade vocal, atribuicao correta das falas e lip sync correto.

Nunca permitir que o modelo decida livremente quem pronuncia uma fala ja atribuida. Usar `TEMPLATE-MESTRE-VIDEO.md` e as regras em `personagens/regras/` como base.
