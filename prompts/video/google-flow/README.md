# Google Flow

## Fonte obrigatória

Todo prompt deve partir de [../../templates/TEMPLATE-MESTRE-VIDEO.md](../../templates/TEMPLATE-MESTRE-VIDEO.md) e consultar [../../../docs/APRENDIZADOS-DE-VIDEO.md](../../../docs/APRENDIZADOS-DE-VIDEO.md).

## Regras

- O Flow não possui memória confiável de prompt ou vídeo anterior; cada prompt deve ser autossuficiente.
- Anexar nesta geração a referência própria de cada personagem.
- A imagem MASTER própria permanece a referência facial primária.
- Vídeos de Sr. Antônio e Beto orientam apenas método e rendering, nunca o rosto de outro personagem.
- Usar `Photorealistic / Warm Cinematic Realism` e as continuidades previstas no template.
- Não usar nomes de estúdios, franquias, obras ou artistas como atalho visual.
- Não permitir que o modelo decida livremente quem fala, qual voz usa ou quem executa o lip sync.

## Baseline validada para teste curto

- `Vídeo → Elementos`, não Frames.
- Referências anexadas como Elementos.
- `9:16`.
- `Veo 3.1 Lite`.
- `x1`.
- `8s`.

A baseline é um ponto de partida de teste, não um formato canônico universal.
