# NOMENCLATURA

## Principios

IDs sao permanentes e nao devem ser reutilizados. O numero sequencial deve usar tres digitos quando aplicavel. Versoes usam `V01`, `V02` e assim por diante. Este padrao vale para novos materiais; arquivos existentes nao devem ser renomeados somente para se adequar a ele.

| Tipo | Padrao | Exemplo |
| --- | --- | --- |
| Personagem | `CHAR-001` | `CHAR-001` |
| Cenario | `LOC-001` | `LOC-001` |
| Temporada | `S01` | `S01` |
| Episodio | `S01E001` | `S01E001` |
| Cena | `S01E001-C01` | `S01E001-C01` |
| Prompt | `PROMPT-S01E001-C01-V01` | `PROMPT-S01E001-C01-V01` |
| Imagem | `IMG-CHAR-001-MASTER-V01` | `IMG-CHAR-001-MASTER-V01` |
| Video | `VID-S01E001-C01-V01` | `VID-S01E001-C01-V01` |
| Audio | `AUD-CHAR-001-V01` | `AUD-CHAR-001-V01` |

Nomes descritivos podem complementar o ID, por exemplo `CHAR-001-MARCOS.md`, sem substituir o ID permanente.
