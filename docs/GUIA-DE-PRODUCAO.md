# Guia de Producao

## Principios

- Usar este repositorio como fonte oficial de verdade.
- Validar continuidade antes de gerar assets finais.
- Registrar prompts, imagens mestre, videos, vozes e decisoes relevantes.
- Marcar como `TODO` ou `A DEFINIR` tudo que ainda nao foi aprovado.

## Organizacao basica

- Personagens ficam em [personagens/](../personagens/).
- Cenarios ficam em [cenarios/](../cenarios/).
- Episodios ficam em [episodios/](../episodios/).
- Prompts ficam em [prompts/](../prompts/).
- Assets ficam em [assets/](../assets/).
- Workflow e checklist ficam em [producao/](../producao/).

## Convencao de IDs

- Personagens: `CHAR-001`
- Cenarios: `LOC-001`
- Episodios: `S01E001`
- Assets: `ASSET-CHAR-001-001`
- Prompts: `PROMPT-CHAR-001-IMAGE-001`

## Producao com IA

Todo material gerado com IA deve ser revisado antes de ser considerado aprovado.

Prompts experimentais nao definem canon. Assets experimentais nao definem canon.

## Aprovacao

Um item so passa a ser canon quando:

1. Foi revisado.
2. Foi aprovado explicitamente.
3. Foi registrado no documento adequado.
4. Recebeu ID quando aplicavel.
