# Episodios

Este diretorio organiza os episodios da serie Família Silva.

Episodios em desenvolvimento nao atualizam canon automaticamente. Apenas acontecimentos aprovados e registrados em [../docs/CONTINUIDADE.md](../docs/CONTINUIDADE.md) passam a valer para a serie.

## Convencao de IDs

Use `S01E001`, `S01E002`, `S02E001` e assim por diante.

## Como criar um episodio

1. Copie [templates/TEMPLATE-EPISODIO.md](templates/TEMPLATE-EPISODIO.md).
2. Preencha premissa, conflito, cenas e prompts.
3. Valide continuidade antes da geracao final.
4. Registre assets e prompts usados.
5. Atualize canon apenas depois de aprovacao.
