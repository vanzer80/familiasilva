# Cenarios

Este diretorio registra cenarios da serie Família Silva.

Somente cenarios aprovados e documentados como canon fazem parte oficialmente da serie.

## Convencao de IDs

Use `LOC-001`, `LOC-002`, `LOC-003` e assim por diante.

## Como criar um cenario

1. Copie [templates/TEMPLATE-CENARIO.md](templates/TEMPLATE-CENARIO.md).
2. Preencha apenas informacoes aprovadas.
3. Use `TODO` ou `A DEFINIR` para campos indefinidos.
4. Vincule referencias visuais aprovadas em [../assets/cenarios/](../assets/cenarios/).
5. Atualize [../docs/CONTINUIDADE.md](../docs/CONTINUIDADE.md) se o cenario virar canon.
